# PC-01~03 계정·비밀번호 설정 테스트 사례

| 항목 | 값 |
|---|---|
| 구현 단계 | `IMP-021` |
| 데이터 | 개인정보가 없는 완전한 테스트 데이터 |
| 점검 항목 | PC-01, PC-02, PC-03 |
| 사례 수 | 10 |
| 결과 범위 | 양호·취약·확인 필요·기준 확인 필요 |
| 점검 기준 묶음 | `0.2.0`, 검토 중 |

## 쉬운 용어

| 화면 용어 | 내부 기술 용어 | 뜻 |
|---|---|---|
| 테스트 사례 | Fixture | 정답을 미리 정해 둔 가상 점검 자료 |
| 점검 기준 묶음 | Audit Pack | KISA 기준과 판정 규칙을 묶은 파일 |
| 실제로 적용된 설정 | Effective policy | 로컬·도메인·기기 관리 설정을 모두 반영한 최종값 |
| 설정 적용 위치 | Policy source | 최종 설정이 적용된 위치 |
| 기준 확인 필요 | REVIEW | 조직 기준이 없어 양호·취약을 확정할 수 없는 상태 |

## 안전 경계

- 실제 사용자명·조직명·비밀번호·PC 이름을 포함하지 않는다.
- 설정을 읽지 못한 경우는 `취약`이 아니라 `확인 필요`로 처리한다.
- PC-02에 조직 비밀번호 기준이 없으면 `양호`가 아니라 `기준 확인 필요`로 처리한다.
- 실제 Windows 수집값은 Windows Collector와 VMware 검증 단계 전까지 사용하지 않는다.
