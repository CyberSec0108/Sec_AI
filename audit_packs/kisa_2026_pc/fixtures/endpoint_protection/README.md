# IMP-024 PC-12~15 합성 Fixture

실제 PC·사용자·조직·제품 자료가 아닌 18개 합성 사례다.

- PC-12: 값 없음·명시적 0·활성 1·수집 실패
- PC-13: 최신 Defender·오래된 서명·기관 최신성 기준 누락·미지원 제품·수집 실패
- PC-14: 실시간 감시 사용·비활성·Defender 수동 모드·수집 실패
- PC-15: Windows 방화벽 사용·합성 대체 방화벽 분기·프로필 비활성·미승인 타사 제품·수집 실패

PC-12는 `DefaultPassword`의 실제 값을 포함하지 않고 존재 여부 boolean만 사용한다. PC-15의 합성 대체 방화벽 Adapter는 분기 시험 전용이며 실제 타사 제품 지원을 뜻하지 않는다.
