# IMP-022 서비스 관리 Fixture

이 폴더는 실제 PC나 실제 조직 이름을 포함하지 않는 합성 시험 데이터만 보관한다.

- 대상: PC-04, PC-05, PC-06, PC-08, PC-09
- PC-07: 기존 `fixtures/pc07`의 17개 사례와 기존 판정 파이프라인을 그대로 사용한다.
- 조직 기준이 필요한 PC-04~06은 기준이 없으면 `REVIEW`로 판정한다.
- PC-09는 IE·IE 모드·WinINet 미사용 범위가 확인된 경우에만 `N/A`로 판정한다.
- `ERROR`를 `FAIL`로 바꾸거나, 기준이 없는데 `PASS`로 바꾸지 않는다.
