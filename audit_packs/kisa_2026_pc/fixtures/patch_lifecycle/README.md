# IMP-023 패치·지원 수명 Fixture

실제 PC나 실제 조직 자료가 없는 합성 시험 사례 12개다.

- PC-10: 최신 누적 보안 패치, 자동 업데이트, 재부팅 대기, 내부 관리 절차를 함께 확인한다.
- PC-11: Edition 그룹과 DisplayVersion별 Microsoft 지원 종료일, 내부 관리 절차를 함께 확인한다.
- `Get-HotFix` 단독 목록으로 PASS하지 않는다.
- 참조 스냅샷 또는 내부 절차가 없으면 `REVIEW`다.
- 패치 누락과 이미 종료된 제품 수명주기는 `FAIL`이다.
- 권한 부족·수집 실패는 `ERROR`다.
