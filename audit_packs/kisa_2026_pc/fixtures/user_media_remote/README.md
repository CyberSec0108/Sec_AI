# IMP-025 PC-16~18 합성 사례

실제 사용자·장비·기관 자료를 사용하지 않는 15개 결정론 시험 사례다.

- PC-16: 사용자별 화면보호기 활성, 600초 이하, 재개 시 암호 보호와 자산 사용자 Coverage
- PC-17: 모든 드라이브 자동실행 차단, AutoRun 명령 실행 금지, 비볼륨 AutoPlay 차단과 승인된 내부 절차
- PC-18: 요청형 `fAllowToGetHelp`와 제공형 `fAllowUnsolicited`의 명시적 비활성

PC-16의 SID는 형식 시험용 합성값이며 사용자명은 포함하지 않는다. PC-17 절차 ID도 합성값이다. PC-18은 Windows Remote Assistance만 다루며 Quick Assist와 원격 데스크톱은 별도 기능이라 이 Control의 판정에 넣지 않는다.
