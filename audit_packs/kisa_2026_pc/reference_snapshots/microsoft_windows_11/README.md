# Microsoft Windows 11 참조 스냅샷

이 폴더는 PC-10 패치 기준과 PC-11 제품 지원 종료일을 특정 기준일에 고정한 개발용 참조 자료를 보관한다.

- 원본 권위: Microsoft Learn·Microsoft Support
- 현재 기준일: 2026-07-23
- 다음 월간 보안 업데이트 전 만료: 2026-08-10 23:59:59 UTC
- 승인 상태: `DRAFT`, 서명 없음, 합성 시험 전용
- 운영 사용: 금지. 실제 승인자 서명과 반입 절차가 끝난 스냅샷만 운영 판정에 사용할 수 있다.

PC-10은 누적 업데이트의 최소 Build·UBR을 비교한다. 더 높은 누적 Build는 이전 보안 수정사항을 포함하므로 통과할 수 있지만, 단순 `Get-HotFix` 목록만으로는 판정하지 않는다.

PC-11은 Edition 그룹과 DisplayVersion을 함께 사용한다. “가장 최신 Feature Version”과 “아직 Microsoft 지원 중인 Version”은 같은 뜻이 아니다.
