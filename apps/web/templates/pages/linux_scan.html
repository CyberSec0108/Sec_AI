Linux 서버 점검

Linux 서버의 U-01~U-67 항목을 읽기 전용으로 확인합니다. 서버 종류와 버전은 시스템이 자동으로 확인합니다.

서버 설정을 변경하지 않습니다. 등록된 시험 장비에 SSH 키로 접속해 고정된 읽기 전용 명령만 실행하며, 명령·원문·정규화 결과의 SHA-256 확인값을 남깁니다.
회사 등록 장비가 아닌 내 서버를 점검하시나요? SSH 주소나 key를 등록하지 않는 Linux 원샷 자가 점검을 사용하세요. 두 방식의 결과는 서로 섞이지 않습니다.
