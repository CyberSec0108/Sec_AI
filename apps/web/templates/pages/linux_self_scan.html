내 Linux 서버 점검

SSH 정보를 등록하지 않고 서버 안에서 점검 프로그램을 한 번 실행합니다.

1단계 · 점검 만들기

점검을 준비하세요

서버 종류와 버전은 프로그램이 자동으로 확인합니다. 사용자는 배포판을 직접 선택하지 않습니다.

일반 권한과 추가 권한은 어떻게 다른가요?

먼저 운영체제·시간·패키지 목록처럼 일반 권한으로 볼 수 있는 3개 자료를 확인합니다. 그 뒤 계정 정책·SSH·파일 권한·서비스 등 39개 자료가 더 필요하면 목록을 보여주고 동의를 받습니다. 비밀번호 입력은 Linux의 sudo가 직접 처리하며 Sec_AI는 읽거나 저장하지 않습니다.

2단계 · 프로그램 연결

서버에서 프로그램을 실행하고 아래 코드를 입력하세요

  1. Linux 통합 점검 프로그램을 받습니다.

    서명 파일을 확인하고 있습니다.

    점검 프로그램 다운로드 화면 열기
  2. 실행 권한을 한 번 부여합니다.

    chmod +x secai-linux-check-x86_64

  3. 프로그램을 실행합니다.

    ./secai-linux-check-x86_64 — 프로그램이 배포판을 자동 확인하며 token이 들어간 명령은 사용하지 않습니다.

  4. 프로그램이 물으면 일회용 코드를 입력합니다.

오프라인 결과 수동 업로드

프로그램이 만든 ZIP과 같은 이름의 descriptor JSON을 선택합니다. 자가 제출이므로 장치 신원은 자동 인증되지 않으며 결과 보증 수준은 LOW입니다.
