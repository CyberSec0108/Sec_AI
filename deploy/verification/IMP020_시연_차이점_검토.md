## 2. 시연 안정화 반영

- Docker embedded DNS `127.0.0.11`을 5초 유효기간으로 사용해 Gateway가 API upstream 주소를 runtime에 다시 해석하도록 변경했다.
- Gateway를 재생성하지 않고 API 컨테이너만 교체한 실험에서 Gateway container ID가 유지됐고 6회 polling 안에 HTTP 200으로 자동 복구됐다.
- `nginx -t`, Gateway healthcheck와 전체 readiness가 통과했다.
- `tools/demo.ps1`은 Core readiness와 PASS·FAIL·ERROR·변조·replay·상세 계약을 한 번에 검증한다.
