## 1. 개정 결과

사용자 기능을 AI·복구 작업 뒤에 몰아두던 순서를 다음과 같이 바꿨다.

```text
IMP-039 제출·서명 공격시험
→ IMP-040~043 1~2클릭 점검·진행·결과·재점검·관리자 동의
→ IMP-044~046 Queue·저장소 복구·인증/RBAC/Web 보안
→ IMP-047~052 KISA RAG·LLM·Chat 계약과 불변성
→ IMP-053~054 실제 AI 기능 전환·사용성 인수
→ IMP-055~062 clean VM·조직 서명·Pilot 인수
```

브라우저만으로 Windows 설정을 읽지 않고 Windows Launcher가 Collector와 로컬 서비스를 연결하도록 계획했다. 설치·실행 후 일반 사용자는 PowerShell 또는 Docker 명령 없이 화면에서 1~2번의 선택으로 점검을 시작하는 것을 완료 기준으로 삼는다.

## 2. 향후 기능 더미 UI 계약

- `LIVE`: 실제 API·권한검사·감사·자동시험이 연결된 기능
- `PREVIEW`: 비식별 고정 예시만 표시하며 실제 수집·저장·제출·판정을 호출하지 않는 기능
- `BLOCKED`: 보안 Gate와 해제 조건을 표시하고 직접 URL에서도 서버가 거부하는 기능
- `HIDDEN`: 별도 역할·권한이 필요한 내부 기능

미리 보기 데이터는 runtime DB, Finding과 감사 정본에 저장하지 않는다. 실제 기능처럼 보이는 활성 버튼을 제공하지 않으며, 같은 화면과 view model에서 검증이 끝난 기능만 `LIVE`로 전환한다.
