# Linux UI 등록 서버·자동 식별 화면 검증

## 1. 변경 목적

Linux 중앙 SSH 점검 화면의 Ubuntu/Rocky 카드가 배포판 선택처럼 보이던 문제를 수정했다.
사용자는 등록된 서버 별칭만 선택하고, 운영체제·버전·architecture는 SSH 사전 확인 뒤 결과로
표시한다.

## 2. 변경 결과

- 개발 기본 별칭을 `Linux 시험 서버 A`, `Linux 시험 서버 B`로 변경했다.
- `/api/v1/linux/assets` 공개 표현에서 내부 `distribution`을 제거했다.
- 카드에는 `등록된 SSH 서버`와 `운영체제는 연결 후 자동 확인`만 표시한다.
- 시작 버튼을 `Linux 서버 자동 확인 및 점검 시작`으로 변경했다.
- `PLATFORM_IDENTIFIED` SSE를 받아 감지된 제품명·버전·architecture와 지원 안내를 표시한다.
- `Ubuntu·Rocky 전용 명령` 문구를 `확인된 서버에 맞는 읽기 전용 명령`으로 변경했다.
- 배포판 충돌 오류는 사용자 선택 오류가 아니라 등록 정보와 실제 서버의 불일치로 안내한다.

내부 등록 대상에는 안전 교차 확인용 예상 배포판이 계속 존재한다. 이 값은 사용자가
선택하거나 공개 API에서 덮어쓰는 값이 아니며 실제 `/etc/os-release`와 다르면 실행을
차단한다.

## 3. 서버 등록 기능 상태

현재 중앙 SSH 대상은 환경변수, 외부 private key 파일과 `known_hosts`로 정적 등록된 개발
시험 서버다. Web 등록·DB 자산 저장·서버별 Secret/KMS·host key 확인·조직 승인 기능은 아직
구현하지 않았다. 단계별 설계는
[`Linux SSH 서버 등록 기능 구현 계획`](../../docs/plans/Linux_SSH_서버_등록_기능_구현_계획.md)에
기록했다.
