# SWITCH-05 안전 기본 판정 기준 검증

## 1. 목적

Aruba N-01~N-38 결과의 `확인 필요`를 줄이기 위해 장비 수집값을 임의 생성하는 대신,
KISA 기반 안전 판정 기준을 기본으로 제공하고 회사·기관별 수정 경계를 연결한다.

## 2. 구현 결과

- 26개 닫힌 구조화 기준을 기본 제공한다.
- 로그인 실패 잠금 허용 상한은 5회, 나머지 보안 설정은 `필수 적용`이 기본이다.
- 숫자는 서버 허용 범위로 검증하고 선택값은 boolean만 허용한다.
- raw command·자유형 JSON·정규식·SQL은 입력할 수 없다.
- 사용자는 기준을 수정하거나 `기본 점검값으로 되돌리기`로 초기화할 수 있다.
- 브라우저 보존값과 실행 시점 criteria snapshot을 분리하며 실행 결과에 criteria SHA-256을 저장한다.

## 3. 수집값 불변 경계

판정 기준은 `expected_summary`와 규칙 입력에만 사용한다. AOS-CX REST projection,
`observed_summary`, Evidence와 원본 projection hash는 기준값으로 채우거나 덮어쓰지 않는다.
동일 REST projection에서 기준을 변경하면 criteria/result hash와 적용 기준 문구만 바뀌며,
N-21 실제 확인값과 REVIEW 상태는 그대로임을 자동시험으로 확인했다. 실제 값이 없는 항목은
기준만으로 PASS가 되지 않는다.
