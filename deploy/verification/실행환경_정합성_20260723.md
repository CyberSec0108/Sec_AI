## 1. 발견한 불일치

최초 확인 시 Docker Desktop Linux engine이 정지해 모든 Sec_AI 컨테이너와 Web UI가 실행되지 않았다. Docker Desktop을 기동하자 기존 컨테이너가 복구됐지만 다음 불일치가 확인됐다.

- Gateway가 문서 기준 `127.0.0.1:18480`이 아니라 오래된 `127.0.0.1:8080` 설정으로 실행됨
- API image 내부가 IMP-021 현재 source가 아닌 초기 health-only 골격이었음
- API image에 `account_policy.html`과 `pack-0.2.0.json`이 없었음

## 2. 재동기화 조치

`tools/core.ps1 -Action Up`을 사용해 현재 프로젝트 source로 모든 프로젝트 image를 재빌드하고 migration `0001_imp018`, `0002_imp019`를 적용했다. 기존 PostgreSQL·Redis·AIStor named volume을 삭제하거나 초기화하는 명령은 사용하지 않았다.

재빌드한 프로젝트 image namespace:

```text
sec-ai-mvp/aistor:0.1.0
sec-ai-mvp/audit-api:0.1.0
sec-ai-mvp/audit-worker:0.1.0
sec-ai-mvp/audit-scheduler:0.1.0
sec-ai-mvp/clamav:0.1.0
sec-ai-mvp/gateway:0.1.0
sec-ai-mvp/postgres:0.1.0
sec-ai-mvp/redis:0.1.0
```
