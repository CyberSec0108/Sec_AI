|---|---|

| 화면 | `/ui/help?topic=vulnerability` |
| UI 계약 | `product-help-v4` |

## 변경 결과

- 기능별 도움말에 `알려진 취약점` 탭을 추가하고 선택 상태를 키보드·스크린리더가
  확인할 수 있도록 `aria-current="page"` 계약을 적용했다.
- Windows 10·11 x64 OS·업데이트·설치 프로그램과 Python·Node.js·Java 패키지를
  현재 비교 대상으로 표시했다. Linux와 네트워크 장비는 아직 이 기능의 지원 대상이
  아님을 함께 안내한다.
- 최근 Windows PC 점검 완료, 선택형 의존성 파일 추가, 공개 자료 비교, 구성요소별
  후보 확인, 공식 자료 기반 한글 설명과 선택형 AI 설명 확인 순서를 설명했다.
- 공개 자료 일치는 `영향 가능성 후보`일 뿐 공식 취약 판정이 아니며, 후보가 없어도
  안전을 확정하지 않는다는 기존 판정 경계를 유지했다.
- 도움말에서 실제 `/ui/vulnerability-check` 화면을 바로 열 수 있게 했다.

`3. KISA 근거 질문`이 현재 화면에 없어 실패했다. 이번 변경과 직접 연결된 도움말 전용
시험은 별도로 통과했으며, 기존 기대값은 요청 범위 밖이므로 수정하거나 약화하지 않았다.

조직의 공식 Finding으로 승격하지 않는다. 실제 조치 전에는 제조사 보안 권고와 조직
절차를 함께 확인해야 한다.
