# IMP-054 관리자 결과 표시·재실행 복구 검증

검증 시각: 2026-07-25 14:29 KST

## 변경 결과

- 제품 CSP에서 일반 Launcher `127.0.0.1:18481`과 관리자 결과 bridge `127.0.0.1:18482`만 정확히 허용했다.
- 관리자 결과를 한 번 읽으면 `18482` one-shot bridge를 종료하고, 일반 Launcher의 관리자 실행 상태를 `NOT_REQUESTED`로 되돌린다.
- 결과 화면 상단에 `관리자 점검 결과` 전용 패널과 `관리자 점검 다시 하기` 버튼을 추가했다.
- 관리자 결과 token은 fragment에서 회수하고, 연결 시작이 늦을 때 최대 10초 동안 재시도한다.
- 비식별 관리자 결과를 현재 탭의 `sessionStorage`에 보관해 화면 새로고침 뒤에도 마지막 결과 위치를 찾을 수 있게 했다.
- 일반·관리자 수집의 원본값은 메모리에서만 DRAFT 규칙에 전달한다. 브리지와 이력에는 안전한 `실제 확인값·판정 기준·판정 이유 코드·시험 상태`만 보낸다.
- 시험 상태는 `PASS·FAIL·ERROR·REVIEW·N/A`이며 공식 Finding을 생성하거나 저장하지 않는다.
- 관리자 항목을 PowerShell 명령 뒤의 개별 인자로 붙이던 결함을 제거하고, allowlist 순서가 검증된 CSV 한 값으로 전달한다.
- PowerShell `List.Add()`의 내부 순번이 결과 JSON 앞에 출력되지 않도록 반환값을 폐기한다.
- 새 EXE가 기존 Sec_AI Launcher를 발견하면 전용 내부 요청으로 기존 서버를 정상 종료하고 최대 5초 안에 `18481` 포트를 인계받는다.
- 다른 프로그램이 `18481`을 사용하거나 기존 서버가 응답하지 않으면 Python 오류 추적 대신 재시도 안내를 표시한다.
