## 변경 결과

- Windows 도움말에 Windows 11 x64 `지원됨`, Windows 10 x64 `부분 지원`,
  Windows Server·Domain Controller `지원 안 함`을 구분했다.
- Linux 도움말에 Ubuntu 24.04·Rocky 9 `지원됨`과 Ubuntu 22.04·Debian 12·RHEL 9·
  AlmaLinux 9 `시험 지원`을 표시했다. x86_64만 허용하고 ARM64·목록 밖 버전은 차단한다고
  안내한다.
- Linux 중앙 SSH 점검과 공용 실행 파일 자가 점검을 각각 바로 열 수 있게 했다.
- 네트워크 도움말의 오래된 `준비 중` 안내를 현재 AOS-CX 10.13 REST 점검,
  N-01~N-38 개발용 DRAFT 결과·PDF 흐름으로 교체했다. Cisco IOS XE·기타 스위치는
  실제 Adapter 인수 전 `지원 안 함`으로 표시한다.
- 계정 도움말에 관리자 Linux 서버 등록·연결 확인 기능을 반영했다.

## 검증

```text
도움말 탭·지원 버전 계약 Pytest: 2 passed
변경 시험 Ruff: All checks passed
재빌드 API image의 지원 문자열 확인: PASS
API health: ok
API ready: PostgreSQL·Redis·AIStor·ClamAV true
```

지원 상태는 실제 Catalog와 인수 근거를 따른다. 신규 Linux 네 종류와 Windows 10은 실제
VM Gate가 남아 있으므로 도움말에서도 `지원됨`으로 과장하지 않는다.
