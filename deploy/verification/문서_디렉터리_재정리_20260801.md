## 1. 정리 원칙

루트에는 프로젝트를 시작할 때 바로 읽는 다음 문서만 유지한다.

- `AGENTS.md`
- `README.md`
- `구현_현황.md`
- `보안_정책.md`

나머지 장기 문서는 다음처럼 분류했다.

```text
docs/
├─ README.md                  전체 문서 통합 목차
├─ adr/                      번호 의사결정과 승인·hash Index
├─ plans/                    현재·후속 제품과 제출 계획
└─ guides/                   초보자·일반 사용자 안내
```

## 2. 이동한 문서

- `ADR_docs/` 전체 → `docs/adr/`
- `다음_I_J_단계_계획.md` → `docs/plans/다음_I_J_단계_계획.md`
- `대화_RAG_제품_계획.md` → `docs/plans/대화_RAG_제품_계획.md`
- `플랫폼_확장_및_보조_조치_계획.md` → `docs/plans/플랫폼_확장_및_보조_조치_계획.md`
- `제출_평가_정합성_및_제품_로드맵.md` → `docs/plans/제출_평가_정합성_및_제품_로드맵.md`
- `초보자_사용_안내.md` → `docs/guides/초보자_사용_안내.md`
- `사용자_정의_점검기준_안내.md` → `docs/guides/사용자_정의_점검기준_안내.md`

## 3. 제자리에 유지한 문서

`deploy/verification`, `audit_packs`, `database`, `requirements`, `portable`, `guides`, `tests` 아래 README와 검증 기록은 코드·자료·산출물의 사용법 또는 당시 증적이다. 중앙 문서로 이동하면 상대경로와 추적 관계가 약해지므로 원래 위치에 유지하고 `docs/README.md`에서 찾을 수 있게 했다.

## 4. 검증 범위

- 전체 Markdown 상대 링크 존재 여부
- 이전 `ADR_docs/` 경로 잔존 여부
- 루트 Markdown 파일 최소화
- ADR 번호 문서 20개와 SHA-256 Index 일치
- `AGENTS.md`, `README.md`, `구현_현황.md`의 새 문서 경로 일치

문서 전용 변경이므로 Python test, Ruff, mypy, JSON Schema test와 Docker 재빌드는 실행하지 않는다.
