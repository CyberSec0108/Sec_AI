## 4. Fixture 계약

Input envelope의 `evidence` 배열 각 항목은 기존 `normalized_evidence.schema.json`을 통과한다. Envelope 자체는 여러 증적을 한 시험 case로 묶는 test-only 구조다.

Expected 파일은 아직 존재하지 않는 Finding Builder의 결과를 가장하지 않는다. 다음 항목만 고정한다.

- `expected_status`
- applicability status·reason
- aggregate subject
- result code
- candidate·evaluated·excluded·violating volume ID
- error code
- rationale code

`IMP-016`은 이 projection을 이용해 Schema-valid Finding과 input/output hash를 생성해야 한다.

`index.json`은 각 parsed input·expected JSON의 RFC 8785 canonical SHA-256을 고정한다.
