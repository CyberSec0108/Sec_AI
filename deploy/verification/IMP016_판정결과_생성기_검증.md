# IMP-016 Finding Builder·canonical hash 검증 기록

| 항목 | 결과 |
|---|---|
| 구현 ID | `IMP-016` |
| 상태 | `PASS` |
| Runtime | CPython `3.14.6`, Docker `linux/amd64` |
| 입력 | PC-07 DRAFT Pack, Schema-valid normalized evidence, immutable `DecisionCandidate` |
| 출력 | Schema-valid 개발 Finding과 canonical input/output SHA-256 |
| 기준일 | 2026-07-22 |

## 1. 구현 결과

- `FindingBuilder`가 Pack·evidence Schema와 Pack content hash를 fail-closed로 검증한다.
- 17개 PC-07 Fixture의 `PASS/FAIL/ERROR` decision을 `finding.schema.json`에 맞춘다.
- `rule_result.actual`에는 평가된 volume별 실제 filesystem, `expected`에는 `NTFS`를 기록한다.
- `rationale_code`와 Pack의 KISA 571~572쪽 citation을 Finding에 직접 연결한다.
- evidence ref는 evidence ID 순으로 정렬하고 RFC 8785 JCS set hash를 계산한다.
- Finding ID는 canonical input/output hash에서 UUIDv5로 만들며 입력 순서와 실행 시각에 흔들리지 않는다.

## 2. Canonical hash 계약

### 2.1 Input hash

`rule_result.input_sha256`은 다음 canonical input object의 RFC 8785 JCS SHA-256이다.

- Finding Schema ID·version
- organization/job/asset/Control/subject
- exact Pack ID·version·content hash·approval
- applicability/evaluation rule ID·version·parameter
- Rule Engine version·artifact SHA-256
- 전체 normalized evidence를 evidence ID로 정렬한 배열
- evidence refs와 evidence set SHA-256
- policy/reference refs
- 고정 `evaluation_as_of`

증적 ref의 기존 hash가 그대로여도 normalized evidence 값이나 provenance가 변조되면 input hash가 달라진다.

### 2.2 Output hash

`rule_result.output_sha256`은 Finding에서 다음 field만 제외한 decision payload의 RFC 8785 JCS SHA-256이다.

- 실행 envelope: `id`, `created_at`, `correlation_id`, `evaluated_at`
- 자기 참조: `rule_result.output_sha256`

따라서 실행 시각 변경은 output hash를 바꾸지 않지만 status, actual/expected, result/rationale,
input hash, engine identity, Pack/rule/evidence lineage 변경은 output hash를 바꾼다.

## 4. 책임 경계

현재 PC-07 Pack `0.1.0`은 개발용 `DRAFT`다. Builder 기본값은 DRAFT를
`PACK_NOT_APPROVED`로 거부하며 `allow_draft=True`를 명시한 합성 Fixture 시험에서만
Schema-valid 개발 결과를 만든다. 승인·서명·활성화된 exact Pack, 전용 Evaluation Worker와
append-only 저장 경로가 연결되기 전에는 운영 공식 Finding이 아니다.

다음 기능은 IMP-016에 포함하지 않았다.

- 동일 입력 100회 replay와 repository 멱등 key (`IMP-017`)
- Pack 활성 assignment와 Evaluation Worker service identity 검증
- PostgreSQL append-only 저장·Outbox·Queue
- 실제 Windows 증적·Collector·업무 API
