# Sec_AI 현재 상태·문서 동기화 검증 — 2026-08-03

> 이 문서는 2026-08-03 코드, 실행 컨테이너, PostgreSQL, VMware 시험 장비와 집중시험을 기준으로 ADR·진행 문서를 동기화한 기록이다.

## 1. 확인한 실제 상태

| 영역 | 확인 결과 |
|---|---|
| Core | API, Worker, Gateway, Model Gateway, PostgreSQL/pgvector, Redis, AIStor, ClamAV가 실행 중이며 API health가 정상이다. |
| 검색 모델 | `BAAI/bge-m3` 1024차원 embedding service와 `BAAI/bge-reranker-v2-m3` reranker service가 실행 중이다. 모델 cache는 각각 전용 Docker volume에 보존한다. |
| 검색 세대 | PostgreSQL에 기존 32차원과 신규 1024차원 ACTIVE generation을 병렬 보존하며, BGE-M3 vector 908건을 확인했다. 현재 mode는 `BGE_M3_WITH_LEGACY_FALLBACK`이다. |
| 전체 가이드 질의 | KISA PDF의 분류·Control namespace를 저장하고 PC·UNIX/Linux·Switch·Network·Web 범위의 복합·비교·모호 질문을 위한 query expansion과 reranking 경로가 있다. |
| Windows | PC-01~18 읽기 전용 수집, DRAFT 규칙 판정, 별도 AI 설명, PDF와 후속 질문 흐름이 구현되어 있다. clean Windows 11, 조직 서명, SmartScreen과 Pilot은 미완료다. |
| 점검 기준 | 개인/조직 Profile, 선택 이력, 실행 시점 snapshot과 KISA 기본값 되돌리기가 구현되어 있다. 자유 명령이나 임의 규칙 코드는 허용하지 않는다. |
| Linux | Ubuntu 24.04와 Rocky Linux 9 전용 읽기 Adapter, KISA UNIX U-01~U-67, 실시간 진행·중단, 결과·증적·AI 설명·PDF·후속 질문 경로가 구현되어 있다. |
| VMware | Ubuntu 24.04와 Rocky Linux 9 시험 VM이 VMware에 등록·실행 중이며 `secai-initial-vulnerable` snapshot을 확인했다. |
| Switch | Cisco IOS XE와 Aruba AOS-CX의 공통 결과/Adapter 계약과 fail-closed 합성시험은 있으나, 공식 vendor image와 실제 장비 E2E 인수는 미완료다. |
| Agent/MCP | 설계와 승인형 경계만 존재하며 실제 설정 변경 기능은 구현 완료가 아니다. |

- Alembic head: `0020_guide_id_length`
- 32차원·1024차원 ACTIVE generation 병렬 존재
- BGE-M3 1024차원 vector 908건
- Ubuntu·Rocky Linux 완료 run 존재
- API image manifest: `sha256:19a5236551c84dbb5418d8f7484a0b223f32f5ef350f5ad242037576535edbc6`

## 3. 완료로 보지 않는 항목

- Windows `IMP-055~062` clean VM·조직 서명·SmartScreen·Pilot
- BGE-M3 전환의 정식 offline recall/MRR/citation/p95 비교와 운영 승인
- Linux 정상/취약 snapshot 반복 재현성·Pack 승인/서명·운영 자격증명 인수
- Cisco·Aruba 공식 image 이용조건 승인, 실제 VM/장비 수집·UI·PDF·AI E2E
- 로컬 vLLM 실제 추론과 외부 egress 0 인수
- Agent/MCP 승인형 조치 실행

## 4. 문서 판정 원칙

- 코드가 있고 집중시험과 Runtime 연결을 확인한 항목은 `개발 환경 구현`으로 기록한다.
- 실제 장비, 서명, 운영 권한, vendor image 또는 품질 benchmark가 남은 항목은 `부분 완료` 또는 `인수 대기`로 기록한다.
- DRAFT Audit Pack 결과를 운영 공식 Finding으로 표현하지 않는다.
- 이 기록은 전체 표준 Gate나 운영 승인 서명을 대체하지 않는다.
