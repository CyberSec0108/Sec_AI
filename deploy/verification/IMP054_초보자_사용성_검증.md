# IMP-054 초보 사용자 최종 사용성 검증

## 1. 결과

`IMP-054`는 현재 개발 PC 기준으로 **완료**했다. `http://localhost:18480`의
시작 화면, 점검 결과, KISA 질문, 도움말을 `점검 → 결과 → KISA 근거 질문`
흐름으로 연결했고, AI 설명과 공식 점검 결과의 역할을 분리했다.

이번 완료는 **개발 PC 조건부 인수**다. 깨끗한 Windows 11 VM, 실제 초보
사용자와 운영 보안 통제를 함께 확인하는 최종 인수는 `IMP-055~061`에서
수행한다. 운영 배포와 Pilot은 승인하지 않았다.

## 2. 사용자 요청 반영

- `새 대화·최근 대화`가 있는 왼쪽 패널과 `답변 근거·출처`가 있는 오른쪽
  패널을 각각 접고 펼칠 수 있다.
- 640px 이하 화면에서는 두 보조 패널을 기본으로 접고, 용도를 알 수 있도록
  `대화 패널 펼치기`, `출처 패널 펼치기` 문구를 표시한다.
- SSE 완료 이벤트와 생성 요청 종료 양쪽에서 현재 대화를 다시 읽어, 다른
  페이지로 이동하지 않아도 완료 답변이 즉시 표시된다.
- 생성 중에는 `질문 확인 → KISA 원문 검색 → 답변과 출처 정리` 3단계
  인디케이터를 표시한다.
- 새 로컬 답변은 `핵심 답변 / 확인 기준 / 출처 / 알아두세요`로 생성한다.
  기존 한 줄 답변도 안전한 DOM 렌더러가 문장별로 나눠 표시한다.
- 긴 KISA 문단은 문장별 목록으로 나누고, 대화 영역만 스크롤해 현재 질문,
  입력창과 출처를 잃지 않도록 했다.
- 답변 복사, 출처로 키보드 focus 이동, Enter 전송, Shift+Enter 줄바꿈,
  Esc 수정 취소, 글자 수 표시를 제공한다.
- 밝은/어두운 화면, 본문 바로가기, 명확한 focus, 모션 감소 설정과
  데스크톱·태블릿·모바일 반응형을 적용했다.
- 점검 결과의 각 항목에서 KISA 질문 화면으로 이동하면 질문이 미리 채워진다.
  사용자가 확인 후 보내므로 자동 질문이나 자동 판정은 만들지 않는다.

## 3. 안전 경계

- 질문과 승인 KISA 원문은 외부 AI 서비스로 보내지 않는다.
- AI 설명은 PC 설정, 공식 Finding과 기존 판정을 변경하지 않는다.
- 답변과 인디케이터는 `textContent` 기반 DOM으로 만들며 `innerHTML`을
  사용하지 않는다.
- 기술 UUID·hash·model 정보는 기존 `기술 정보 보기` 안에 계속 접어 둔다.
- 이번 검증은 기존 대화 7건을 읽기만 했고 대화·Finding·Pack 검증 자료를
  새로 만들거나 삭제하지 않았다.
- 데이터베이스 migration은 추가하지 않았으며 head는 `0010_imp053`이다.

현재 로컬 답변기는 token 단위 원격 스트림이 아니라 상태 SSE를 사용한다.
이번 수정은 완료 상태를 받는 즉시 답변 본문과 출처를 같은 화면에 다시
표시하고, 기다리는 동안 단계형 상태를 보여주는 계약이다.
