## Source와 Release의 구분

현재 Pack은 PC-07 하나만 포함한 개발 source이므로 `approval.status=DRAFT`다. 문서 결정의 승인은 규칙 설계 승인이고 Audit Pack release 승인은 아니다.

운영 `APPROVED` Pack은 다음 조건을 별도로 충족해야 한다.

- PC-01~PC-18 전체 포함
- 모든 Fixture와 deterministic regression 통과
- 실제 승인자 ID·승인 시각
- 승인 서명과 인증서 신뢰 검증
- 동일 version·content hash 불변성

## Content hash 명확화

Audit Pack 자체에 `content_sha256` field가 있으므로 자기 자신을 포함해 hash를 계산할 수 없다. 따라서 payload projection은 다음으로 고정한다.

```text
SHA-256(RFC8785-JCS(pack - {content_sha256, approval}))
```

이것은 승인 envelope를 payload와 분리하면서 self-reference를 제거하는 구현 명확화다. Schema의 허용 instance 집합은 변경하지 않는다.

고정된 PC-07 Pack content SHA-256:

```text
0849b4b117b1df82c597e5b6737f45664536958a12d996c59879a6a3954618bb
```
