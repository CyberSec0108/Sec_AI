# IMP-031 PC-01~18 Probe·Adapter Coverage 검증

## 1. 완료 범위

| 항목 | 결과 |
|---|---|
| 구현 단계 | `IMP-031` |
| DRAFT Pack | `KISA-2026-PC-MVP 0.6.0`, PC-01~18 |
| Windows native Probe | 20개 exact allowlist |
| 일반 사용자 Probe | 15개, 현재 Windows에서 실제 실행 |
| 관리자 Probe | 5개, 별도 동의·별도 프로세스 구현, 자동 실행 안 함 |
| 서버 기준 입력 | 2개, host fact로 위조하지 않음 |
| host 제품 Adapter | Defender·Windows Firewall DRAFT 내장 Adapter만 허용 |
| 미지원·합성 제품 | host 실행 금지 또는 `REVIEW` |
| 설정 변경 | 실행 전후 차이 0건 |
| 공식 Finding | 생성하지 않음 |
| 다음 단계 | `IMP-032` Online 제출 |

이 단계의 `COLLECTED`는 Windows 자료를 읽었다는 뜻이지 해당 Control이 `PASS`라는 뜻이 아니다. 기관 정책, 사용자 전체 Coverage, 승인 제품 목록과 서버 기준이 필요한 항목은 이 입력이 추가되지 않으면 공식 양호 판정을 만들 수 없다.

## 2. Coverage 분리

| 구분 | 개수 | 처리 |
|---|---:|---|
| Control | 18 | PC-01~18 정확히 1회 |
| Windows host Probe | 20 | Collector fixed allowlist |
| 일반 사용자 Probe | 15 | 현재 사용자 전용 프로세스 |
| 관리자 Probe | 5 | 명시적 동의 후 별도 관리자 프로세스 |
| 서버 reference Probe | 2 | 패치 기준·Windows 수명 기준, host가 생성하지 않음 |

관리자 Probe 5개:

1. `win.security.password-policy` — PC-02
2. `win.network.smb-shares` — PC-04
3. `win.software.messengers` — PC-06
4. `win.boot.entries` — PC-08
5. `win.update.compliance` — PC-10

`imp031_administrator_controls.ps1`은 스스로 UAC를 띄우지 않는다. 이미 사용자 동의를 받은 별도 관리자 프로세스가 아니면 시작 즉시 거부한다. 현재 인수 실행에서는 이 5개를 실제로 시작하지 않았다.

## 4. Adapter 경계

현재 Pack에 연결된 Adapter catalog는 `DRAFT`이며 host 실행 허용 대상은 다음 두 개뿐이다.

- `secai.microsoft-defender-antivirus@0.1.0`
- `secai.windows-firewall@0.1.0`

두 Adapter는 각각 `Get-MpComputerStatus`와 `Get-NetFirewallProfile -PolicyStore ActiveStore`의 고정 source 계약에 묶인다.

- 합성 타사 방화벽 Adapter는 규칙 분기시험 전용이라 실제 host 실행을 금지한다.
- catalog에 없는 백신·방화벽을 제품명 유사성으로 추측하지 않는다.
- 미지원 제품은 자동 `PASS`가 아니라 `REVIEW`다.
- PC-06 메신저는 승인된 제품 catalog와 기관 허용·금지 정책이 아직 없으므로 설치 inventory만 준비하며 양호 판정을 만들지 않는다.
- DRAFT catalog는 운영 `APPROVED` 제품 지원을 의미하지 않는다.

## 7. 보안·오류 처리

- result는 verified plan과 Probe ID·version·Control 순서가 정확히 일치해야 한다.
- record는 flat scalar 객체만 허용하고 key 수·문자열 길이·record 수를 제한한다.
- password·secret·token·private key·사용자명·호스트명·SID·volume label·serial key는 record field로 거부한다.
- Adapter ID·version이 고정 mapping과 다르면 전체 Probe group을 거부한다.
- `ERROR`는 빈 record와 승인 error code를 가져야 하며 Finding으로 변환하지 않는다.
- 관리자 script를 일반 토큰으로 실행하거나 일반 script를 관리자 토큰으로 실행하면 거부한다.
- 자동 UAC, 설정 쓰기 명령과 공식 Finding 생성은 없다.
