## 1. 확인한 문제

답변 본문은 `[1]`만 인용했지만 오른쪽 `답변 근거` 패널에는 검색 후보
`[1]~[5]`가 모두 표시됐다. 검색 후보에는 질문의 직접 근거로 사용되지 않은 다른
Unix 점검 항목도 포함돼 인라인 인용과 출처 패널의 의미가 달라졌다.

원인은 대화 이력 API가 모델 답변에서 실제 사용한 인용 번호를 확인하지 않고,
검색 단계에서 저장된 `ChatCitation` 전체를 메시지의 `citations`로 반환한 것이다.

## 2. 변경 내용

- 대화 이력 응답을 만들 때 답변 본문에 실제 등장한 인용 번호만 반환한다.
- 제한 Markdown renderer가 허용하는 `[1]`, `(1)`, `（1）`, `【1】` 형식을 같은
  번호로 인식한다.
- 원래 citation ordinal은 유지하므로 인라인 번호와 패널 번호, PDF 링크가 같은
  저장 근거를 가리킨다.
- 기존 저장 데이터와 migration은 바꾸지 않아 과거 대화도 다시 조회하는 즉시 같은
  필터를 적용한다.
- 공식 Finding, Audit Pack, 검색 순위와 원문 계보는 변경하지 않는다.
