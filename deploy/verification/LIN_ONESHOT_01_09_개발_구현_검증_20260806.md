## 2. 보안 경계

- 중앙 서비스가 사용자 서버로 SSH 접속하지 않는다.
- 사용자는 서버 IP·SSH 비밀번호·private key·자유 명령을 UI에 입력하지 않는다.
- Collector는 등록된 Probe ID와 exact argv만 읽기 전용으로 실행하고 공식 판정을 만들지 않는다.
- Package scope는 organization·user·job·asset·manifest·nonce·attempt·profile을 archive 처리 전에 검증한다.
- 권한 부족·timeout·출력 초과·수집 실패는 `PASS` 또는 `FAIL`로 바꾸지 않고 `ERROR`로 보존한다.
- 현재 artifact는 `DEV-UNSIGNED`, `download_allowed=false`이며 UI에서 다운로드할 수 없다.

## 6. 완료로 표시하지 않는 항목

1. Ubuntu/Rocky 실제 VM의 추가 권한 거부·취소·`sudo` 실패·timeout·출력 상한·강제 종료
2. 네트워크 실패 뒤 오프라인 업로드와 서비스 재기동 복구
3. 브라우저 접근성·모바일·IDOR·CSRF 공격 E2E
4. PostgreSQL 실제 100회 replay·동시 제출·중간 장애 원자성 시험
5. 프로젝트 밖 조직 Ed25519 private key를 사용한 승인 서명·공개키 배포·폐기 시험
6. 운영 다운로드부터 U-01~U-67 결과 확인까지 전체 사용자 흐름
