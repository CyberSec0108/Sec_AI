## 1. 구현 경계

IMP-028은 실제 Windows Collector가 아니라 protocol test double이다.

```text
엄격한 Manifest JSON
→ 로컬 JSON Schema
→ RFC 8785 content hash
→ 외부 서명 proof와 digest·key ID binding
→ 유효 시간·Job·Asset·endpoint·nonce
→ Collector name·version·release channel
→ 내장 Probe ID·version·Control·권한·timeout·출력·parameter
→ VerifiedExecutionPlan
→ 고정 Mock handler
→ synthetic=true 결과
```

원본 Manifest는 Mock handler에 직접 전달되지 않는다. 모든 Gate를 통과해 좁혀진 `VerifiedExecutionPlan`만 실행할 수 있다.

## 2. 허용 Probe

| Probe | version | Control | 권한 | timeout 상한 | 출력 상한 |
|---|---:|---|---|---:|---:|
| `win.storage.disks` | `0.1.0` | PC-07 | `STANDARD_USER` | 30초 | 65,536 bytes |
| `win.storage.partitions` | `0.1.0` | PC-07 | `STANDARD_USER` | 30초 | 65,536 bytes |
| `win.storage.volumes` | `0.1.0` | PC-07 | `STANDARD_USER` | 30초 | 65,536 bytes |

allowlist에는 자유 형식 command, PowerShell text, script body, Registry path와 WMI query가 없다. `win.storage.volumes`는 고정 parameter `{"include_fixed": true}`만 허용한다.

## 3. 차단 확인

다음 입력은 Probe 실행 전에 안정된 오류 코드로 거부된다.

- content hash가 맞지 않는 변조 Manifest
- 서명 대상 digest 또는 외부 signature proof가 맞지 않는 Manifest
- 시작 전·만료된 Manifest
- 다른 Job·Asset·endpoint·nonce
- 재사용 또는 확인할 수 없는 nonce
- 다른 Collector version·release channel
- 중복되거나 allowlist에 없는 Probe
- 다른 Probe version·Control·권한·parameter
- 내장 상한을 늘린 timeout·출력 크기
- 자유 형식 `command` 필드
- 중복 JSON key, BOM·잘못된 UTF-8과 256 KiB 초과 입력

Collector process 안에서 같은 nonce를 두 번 실행하는 경우도 `REPLAY_DETECTED`로 차단한다. 재시작을 가로지르는 원자적 서버 nonce 예약은 온라인 제출 단계에서 다시 검증한다.

## 6. 보류 사항과 다음 단계

- 이 단계의 `ManifestSignatureProof`는 실제 공개키 검증 adapter를 대신하는 protocol 경계다. 운영 전 내장 공개키·key rotation·폐기와 실제 Ed25519 검증을 연결해야 한다.
- 실제 OS·Registry·CIM·PowerShell·저장 장치를 읽지 않는다.
- 권한 상승, package 생성·제출, PyInstaller EXE와 Authenticode는 아직 없다.
- DRAFT Audit Pack을 운영 `APPROVED`로 바꾸지 않는다.

다음은 `IMP-029`다. Windows 11의 OS·Build·권한·SID context와 PC-07 저장 장치 정보를 읽기 전용으로 수집하되, 설정 변경·자동 상승·공식 Finding 생성을 금지한다.
