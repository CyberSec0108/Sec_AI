## 플랫폼을 추가하는 방법

각 신규 플랫폼은 독립 세로 기능으로 추가합니다.

1. 공식 가이드·vendor 자료와 이용조건 확보
2. exact fingerprint·지원 version·architecture 정의
3. 읽기 전용 allowlist Adapter
4. 정규화 Schema와 증적 hash
5. DRAFT Audit Pack·Fixture·false PASS 회귀
6. 결과·PDF·AI projection
7. 실제 정상·취약·권한 부족 장비/VM 반복시험
8. 조직 승인·서명 후 Catalog 게시

제조사나 OS 계열이 비슷하다는 이유로 기존 Adapter를 그대로 실행하지 않습니다.

## AI 보조 원칙

- AI는 실제 확인값과 공식 규칙 상태를 설명합니다.
- 모델 일반지식은 출처와 구분합니다.
- 완성 설명을 저장하고 화면 진입만으로 재생성하지 않습니다.
- 가이드 문단과 모델 출력은 비신뢰 입력으로 처리합니다.
- AI가 규칙, Pack 승인 상태 또는 장비 설정을 바꾸지 않습니다.

## Agent/MCP 시작 조건

처음에는 읽기 전용 `PLAN_ONLY`로 다음만 작성합니다.

- 대상과 문제
- 제안 작업
- 필요한 권한
- 예상 영향·중단
- backup·rollback
- 승인자
- 재점검 방법

실제 실행은 exact action allowlist, 두 사람 승인, dry-run, timeout, 멱등성, rollback과 성공 후 재점검이 모두 있을 때만 별도 Gate로 추가합니다.
