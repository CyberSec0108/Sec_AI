## 공통 완료 기준

계획은 다음을 모두 만족해야 완료로 바꿉니다.

1. 실제 source·Schema·migration이 일치합니다.
2. 정상·권한 부족·변조·timeout·타 조직 접근 시험을 통과합니다.
3. 읽기 전용 수집, 공식 판정과 AI 설명 분리, append-only·RLS 경계를 유지합니다.
4. 관련 `deploy/verification` 기록과 [`../../구현_현황.md`](../../구현_현황.md)를 갱신합니다.
5. 운영 기능이면 조직 승인·서명·KMS·backup·복구 절차까지 확인합니다.
