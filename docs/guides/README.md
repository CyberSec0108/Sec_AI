공통 주의사항:

- 사용자는 Linux 배포판이나 Windows 세부 버전을 직접 고르지 않습니다. 시스템이 읽기 전용 사전 확인으로 자동 식별합니다.
- Linux 중앙 점검 대상 등록은 관리자만 수행합니다.
- AI 설명은 선택형 보조 기능이며 공식 판정과 결과 hash를 바꾸지 않습니다.
- `LIVE`는 개발 환경 연결 상태입니다. 조직 서명·운영 KMS·공식 Audit Pack 승인을 의미하지 않습니다.
