# 대회 제출 문서

오픈소스 개발대회 제출 양식, 심사 대응표, SBOM과 AI 모델·데이터·라이선스 명세를 관리합니다.
현재 기능 완료 상태의 정본은 [`../../구현_현황.md`](../../구현_현황.md)이며, 실행 당시의 시험
증거는 [`../../deploy/verification/`](../../deploy/verification/)에 보존합니다.

개발 상태를 운영 완료나 공식 취약 판정으로 바꾸어 쓰거나, 재배포 권한이 확인되지 않은 공공기관
원본 PDF·모델 파일·비밀정보를 공개 저장소에 포함해서는 안 됩니다.
